# Knot Spot

Knot Spot is a crochet organization app built with React and Firebase. 
It helps users store patterns, track yarn inventory, log project progress, 
and use simple AI tools to estimate project time and recommend yarn.

## Features
- Pattern storage
- Yarn inventory
- Progress tracker
- AI insights
- Firebase backend

## How to run
npm install
npm start
